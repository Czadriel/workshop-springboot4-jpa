# Workshop Spring Boot + JPA

Projeto desenvolvido com foco em aprendizado prático de desenvolvimento Back-End utilizando Java e Spring Boot, aplicando conceitos de arquitetura em camadas, persistência de dados com JPA/Hibernate e construção de APIs REST.

## 📌 Objetivo

Este projeto foi criado para praticar os principais conceitos utilizados no desenvolvimento de aplicações Java modernas, incluindo:

- Criação de APIs REST
- Arquitetura em camadas
- Persistência com Spring Data JPA
- Relacionamentos entre entidades
- Operações CRUD
- Tratamento de exceções
- Integração com banco de dados

---

## 🚀 Tecnologias utilizadas

- Java
- PostgreSQL
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- Banco de dados H2
- Postman
- Git e GitHub
